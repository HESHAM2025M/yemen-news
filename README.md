# أخبار اليمن — خادم مجاني على GitHub (تحديث كل ساعة)

تطبيق أخبار اليمن يعمل الآن **بدون خادم مدفوع**: صفحة على GitHub Pages + مهمة مجانية تجلب الأخبار كل ساعة.

## ما الذي يحدث تلقائياً؟
- كل ساعة، GitHub Actions يشغّل `fetch_news.py`
- يجلب RSS من: المشهد اليمني، يمن مونيتور، أخبار اليمن الآن، الصحوة نت، عدن 24، سما نيوز، نيوزيمن، الجزيرة، العربية
- يحفظ النتيجة في `data/news.json` وينشر الصفحة من جديد
- الرابط يبقى نفسه دائماً، والمحتوى يتجدد

## خطوات الإعداد (10 دقائق، من الهاتف)

### 1. أنشئ حساب GitHub مجاني
افتح https://github.com/signup وأنشئ حساباً بإيميلك. مجاني تماماً، بدون بطاقة.

### 2. أنشئ مستودعاً جديداً
- اضغط زر `+` ثم `New repository`
- الاسم: `yemen-news` (أي اسم)
- اختر `Public`
- اضغط `Create repository`

### 3. ارفع هذه الملفات
في صفحة المستودع اضغط `uploading an existing file` وارفع كل الملفات في هذه الحزمة:
`index.html` + `fetch_news.py` + مجلد `.github/workflows/update.yml`
أو من الكمبيوتر:
```
git init
git add .
git commit -m "أخبار اليمن"
git remote add origin https://github.com/اسمك/yemen-news.git
git push -u origin main
```

### 4. فعّل GitHub Pages
- في المستودع: `Settings` ← `Pages`
- في `Build and deployment` اختر `Source: GitHub Actions`
- احفظ

### 5. شغّل أول تحديث يدوياً
- تبويب `Actions` ← اختر `تحديث أخبار اليمن كل ساعة` ← `Run workflow`
- انتظر دقيقة، ثم افتح الرابط الذي يظهر في `Settings → Pages`
- سيكون شكله: `https://اسمك.github.io/yemen-news/`

### 6. ثبّت التطبيق على الهاتف
افتح الرابط في Chrome على أندرويد ← القائمة ⋮ ← `إضافة إلى الشاشة الرئيسية`.
شارك نفس الرابط مع أي هاتف آخر.

## التشغيل اليدوي على جهازك (للتجربة)
```
python3 fetch_news.py
python3 -m http.server 8000
# افتح http://localhost:8000
```

## ملاحظات
- GitHub Actions المجاني: 2000 دقيقة شهرياً للحسابات المجانية — هذه المهمة تستهلك أقل من 60 دقيقة شهرياً.
- إذا توقف مصدر RSS، يظهر المصدر الآخر تلقائياً، ولا يتوقف التطبيق.
- كل خبر فيه رابط المصدر الأصلي للقراءة الكاملة.
